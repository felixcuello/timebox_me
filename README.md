# TIMEBOX ME

One thing I do every day is to write down stuff that I want to do every day.

I have my notebook and I write down things in my todo list. However my todo list changes very often and there are things
that have to be done in different priorities, and sometimes I have to switch tasks, but I don't want to lose track of
what I was doing before.

So I created this simple tool to help me track my tasks and timebox them.
